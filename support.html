Agens 支持

Agens 是你自己电脑上 Codex 的遥控器：在手机上看 Codex 任务的进度、发指令、批准操作。电脑上有 Agens 桌面版的，还能处理它整理的待办。Agens 和 OpenAI 没有关系，Codex 是 OpenAI 的开源命令行工具，装在你自己的电脑上。

开始使用

  1. 电脑上准备好 Codex：macOS、Linux 或 Windows，装好 Codex CLI，在终端里能正常使用；另需 Node.js 20.11 或更新（用 Agens 桌面版不需要）。
  2. 在电脑上显示配对二维码：在终端运行 npx replica-bridge@latest --pair，或在 Agens 桌面版里点「帮助 › 设置移动版」。
  3. 在手机上配对：打开 Agens，点「继续使用 GitHub」登录，然后在「远程」页点「设置 Remote」，扫电脑上的二维码（扫不了时点「改为手动配对」输入配对码）。第一次配对时，电脑会问是否允许这台手机。

配好以后，电脑出现在「远程」里，打开一个任务就能发指令、看输出、批准操作。

常见问题

  • 电脑显示离线：电脑要开着并联网。没装成后台服务的，运行 npx replica-bridge 的终端不能关；再运行一次同一条命令会显示状态。
  • 提示需要重新配对，或配对码过期：在电脑上重新运行 npx replica-bridge@latest --pair，用手机再扫一次。
  • 为什么要 GitHub 登录：只用来认出哪些电脑是你的。Agens 不申请任何 GitHub 权限，也读不到你的代码仓库。
  • 中转服务器能看到我的内容吗：不能。手机和电脑之间的内容端到端加密，中转服务器只转发它解不开的数据。详见隐私政策和使用条款。
  • 怎么删除账号：设置 › 账户 › GitHub 账号 › 删除账号。会删除中转服务器上的账号和名下所有设备的记录。

Agens Support

Agens is a remote control for Codex on your own computer: follow your Codex tasks, send instructions and approve actions from your phone. With the Agens desktop app on the computer, you can also work through its to-dos. Agens is not affiliated with OpenAI; Codex is OpenAI's open-source command-line tool, installed on your own computer.

Getting started

  1. Have Codex working on the computer: macOS, Linux or Windows, with the Codex CLI installed and working in a terminal, and Node.js 20.11 or later (not needed with the Agens desktop app).
  2. Show the pairing QR code on the computer: run npx replica-bridge@latest --pair in a terminal, or choose Help › Set Up Mobile in the Agens desktop app.
  3. Pair the phone: open Agens, tap Continue with GitHub to sign in, then tap Set up Remote on the Remote screen and scan the QR code on the computer (or tap Pair manually instead and type the pairing code). The first time, the computer asks you to allow the phone.

Once paired, the computer appears in Remote: open a task to send instructions, follow the output and approve actions.

Common questions

  • The computer shows offline: it has to be on and online. Without the background service, keep the terminal running npx replica-bridge open; running the same command again shows its status.
  • Asked to pair again, or the pairing code expired: run npx replica-bridge@latest --pair on the computer again and scan the new code.
  • Why GitHub sign-in: it only tells the relay which computers are yours. Agens asks for no GitHub permissions and cannot read your repositories.
  • Can the relay see my content: no. What passes between the phone and the computer is end-to-end encrypted; the relay only forwards data it cannot decrypt. See the privacy policy and terms of use.
  • How to delete my account: Settings › Account › GitHub account › Delete account. It deletes your account and the records of all its devices on the relay.
